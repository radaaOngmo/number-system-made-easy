Hexadecimal number system

Learn hexadecimal digits 0–9 and A–F.

LEARN THE CONCEPT

Key idea

Hexadecimal is base 16. It uses ten numeric symbols (0–9) and six letters (A–F), where A=10, B=11, C=12, D=13, E=14 and F=15.

WORKED EXAMPLE

2A₁₆ = 2×16 + 10 = 42₁₀.

Quick check

What decimal value does C represent?

Answer: 12
