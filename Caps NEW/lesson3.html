Octal number system

Explore base eight and valid octal digits.

LEARN THE CONCEPT

Key idea

Octal is a base-8 system. Its valid digits are 0, 1, 2, 3, 4, 5, 6 and 7. The place values from right to left are powers of eight.

WORKED EXAMPLE

17₈ = 1×8 + 7×1 = 15₁₀.

Quick check

Is 8 a valid octal digit?

Answer: No
