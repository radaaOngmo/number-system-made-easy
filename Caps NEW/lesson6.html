Binary to decimal

Use positional values to convert binary numbers to decimal.

LEARN THE CONCEPT

Key idea

Multiply each binary digit by its place value (a power of two) and add the results.

WORKED EXAMPLE

1101₂ = 1×8 + 1×4 + 0×2 + 1×1 = 13₁₀.

Quick check

Convert 1010₂ to decimal.

Answer: 10
