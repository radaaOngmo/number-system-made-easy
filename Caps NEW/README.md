# Number System Made Easy — Grade 9 DTI
A responsive educational learning portal developed as a CAP401 digital artefact.

## Pages
- `index.html` — Home page
- `lessons.html` — Lesson catalogue
- `lesson1.html` to `lesson10.html` — Individual learning pages
- `challenge.html` — 50-mark mixed-format assessment
- `certificate.html` — Printable certificate preview
- `about.html` — Project information and team profiles
- `feedback.html` — Feedback form demonstration
- `style.css` and `script.js` — Shared styling and navigation
- `assets/` — Photographs and illustrated background

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Publish on GitHub Pages
Upload the contents of this folder to the repository root so `index.html` is directly in the publishing folder. In repository Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.

## Embed in Google Sites
After GitHub Pages publishes successfully, in Google Sites choose Insert → Embed → By URL and enter the published URL. If the embedded view is awkward on mobile, use a button that opens the website in a new tab.

## Assessment and form limitations
The challenge is a client-side learning activity, not a secure exam. Text answers use automatic accepted-answer matching and equivalent wording may require teacher review. The feedback page is a demo and does not send responses to a database; connect a Google Form for actual collection. The certificate preview does not verify a score.
