Binary number system

Learn binary digits, base two, and place values.

LEARN THE CONCEPT

Key idea

Binary is a base-2 system that uses only 0 and 1. Each position represents a power of two, from right to left: 1, 2, 4, 8, 16 and so on.

WORKED EXAMPLE

1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀.

Quick check

How many digits are used in binary?

Answer: Two
