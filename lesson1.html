What is a number system?

Understand what a number system is and why computers use different bases.

LEARN THE CONCEPT

Key idea

A number system is a way of representing quantities using a set of digits and a base. The four systems in this course are binary (base 2), octal (base 8), decimal (base 10) and hexadecimal (base 16).

WORKED EXAMPLE

Binary uses 0 and 1. Octal uses 0–7. Decimal uses 0–9. Hexadecimal uses 0–9 and A–F.

Quick check

Which system has base 16?

Answer: Hexadecimal
